# 判定（Oracle）方法论草案

> 配套 `docs/漏洞类型与检测手段.md`（漏洞原理与手段目录）。本文件定义**怎么判**：判定单位、探针模型、每类漏洞的全量判定套件、证据分级与判决映射、抗误报/抗抖动机制、执行策略。
>
> **总基调（用户定调）**：目标是把漏洞**检出来**。凡是能触发/验证某类漏洞的途径，**全部用上**，不只挑几个；宁可每个参数花更长时间 fuzz，也要全面。速度让位于覆盖。

## 1. 五条核心原则

1. **全通道并行、就强取证**：对每个待测参数，枚举该漏洞类所有适用的判定原语，**全部发射**；接受其中最强的证据定案，并记录所有命中的通道用于佐证。绝不因“选了一个通道”而漏判。
2. **差分为骨架**：每条主动探针都配一个**良性对照**；判决建立在“活性输入 vs 对照”的**可观测差异**上，而非绝对观测值。这同时带来语义正确性（解决“本职功能被误报成漏洞”，典型如 SSRF）。
3. **证据分级（证据阶梯）**：每次命中归入 铁证 / 可证 / 弱证 三级，映射到判决置信度；多通道独立命中可叠加置信。
4. **带外可选、不必选**：每类都必须包含**不依赖出网**的通道（带内回显 / 差分 / 跨工具 canary / 时序），使 OOB 被禁的环境仍能判定，不整类失明。
5. **抗偶然性内建**：token/canary 唯一且随机；差分必带对照；时序与崩溃需多次重复 + 统计阈值。

## 2. 判定单位与会话

- **判定单位** = （目标工具 target，参数 param，sink 先验）。
- 对每个单位跑一次**判定会话**：在发射台给出的合法基线实参之上，对该参数依次/并行发射“判定套件”里的全部探针，并统一收集五类观测底座的信号。
- **观测底座（信号从哪来）**：
  - 带外：我方回连服务器，按唯一 token 归并 DNS/HTTP 命中。
  - 带内：工具的响应正文 + 报错正文（回显、文件内容、错误指纹、标记反射都在这里找）。
  - 时序：响应时延（需多次测量）。
  - 跨工具：另一个读/写工具的观测结果（canary 读回）。
  - 存活：套件打完后的轻量 ping（崩溃/DoS 信号）。

## 3. 探针模型

一条**探针（probe）** = 五元组：
`(载荷, 预期可观测效应, 观测底座, 良性对照, 命中判据)`

- 载荷：注入到目标参数的值。
- 预期效应：若漏洞成立应产生什么（回连/回显/延时/文件变化/内容差异）。
- 观测底座：去哪看（带外/带内/时序/跨工具/存活）。
- 良性对照：与载荷只差“活性成分”的无害值（差分骨架要求）。
- 命中判据：唯一 token 命中 / canary 精确匹配 / 内容签名匹配 / 时延差超阈值 / A-B 稳定分化。

判定套件 = 某漏洞类的**全部探针集合**。覆盖维度：`技术(原语) × 语境变体 × 目标变体`，三者取并集，全部发射。

## 4. 各漏洞类的全量判定套件

> “全部发射”原则：下列每类的所有探针都打，并对有语境/编码/目标变体的探针做变体展开。

### 4.1 命令注入
- 带外回连：触发服务端向唯一 token 域名发 DNS/HTTP。
- 带内回显：执行输出唯一 canary 的命令，在响应+报错里精确匹配。
- 求值差分：令 shell 计算只有真执行才会出现的结果（如两随机数之积），在输出里找该结果；对照=不求值的字面量。
- 时间盲判：注入可控延时，K 次测量 vs 对照，超阈值判定。
- 跨工具 canary：执行写出 canary 文件的命令，用读工具读回。
- 错误指纹：全程被动观测 shell 报错签名（`sh: ...: not found` 等）。
- 崩溃：套件后 ping，无响应→DoS 发现。
- **语境变体**：对每条技术探针展开多种注入语境——`;`、`|`、`&&`、`||`、换行、`$(...)`、反引号、引号闭合（单/双/无引号上下文）。全部发射。

### 4.2 参数注入
- 良性特征选项（黄金判定）：注入 `--version`/`--help` 类无害但输出特征极强的选项，在响应里找版本/帮助特征文本；对照=普通位置值。
- 未知选项报错指纹：注入不存在的 `--<随机>`，匹配 “unknown option” 类报错（证“抵达 argv 且被当选项解析”）。
- 文件副作用 + 跨工具 canary：诱导以某选项写出 canary 文件，读工具读回。
- 接受/拒绝差分：前导 `-` 的值 vs 转义后的值，行为分化即证据。
- 带外回连：仅当某选项能触发网络时追加。
- **变体**：对候选后端程序展开其已知危险选项族（写文件/读文件/指定上游/钩子）；并对“是否存在 `--` 分隔符”做反推加权。

### 4.3 路径穿越
- 读真实系统文件（本项目采用）：穿越读 `/etc/hostname`、`/etc/passwd` 等标准必存文件，内容签名匹配；对照=基目录内合法路径。**底线**：只读证明越界所需的标准文件，不批量窃密。
- 写穿越 + 跨工具读回：有写工具时，经穿越写到基目录外、另一工具能读到的位置，再读回。
- 越界/深度差分：穿越路径 vs 合法路径的内容或报错分化；逐级增加 `../` 深度至行为变化。
- 错误指纹：报错泄露解析后的绝对路径，证明穿越被真实解析到基目录外。
- **编码变体**：`../`、`..%2f`、`%2e%2e`、`....//`、绝对路径、（历史）空字节等，全部发射做差分。

### 4.4 SSRF
- 信任边界差分（核心）：目标集 = {回环 `127.0.0.1` 及内部端口、内网段、云元数据 `169.254.169.254`} vs 良性外部对照 URL；只有内网目标产生可区分反应（内容/行为/时序）才判真 SSRF。
- 全读回带：检查被抓取内容是否出现在响应里（全读型，最强）。
- 带外回连 + 边界语义校验：收到带 token 回连证明“发起了请求”，**必须**叠加边界判别，排除“抓 URL 本就是功能”的误报。
- 时序差分：内网可达但被过滤→挂起/超时 vs 不存在→快速失败。
- 重定向 / DNS 变换探针（进阶）：绕“仅校验首个 URL”的防护。
- **目标变体**：多家云元数据端点 + 常见内网服务端口，全部尝试。

### 4.5 查询注入（第二阶段，SQL 代表）
- 布尔差分（核心）：真/假条件返回结果集差异。
- 时间盲注（核心）：条件延时。
- 错误型：畸形输入触发 DB 语法错指纹。
- 联合查询 / 带外：进阶取数/外带。
- **方言变体**：主流 DB 方言各试。

### 4.6 代码注入（第二阶段）
- 求值差分：算式求值结果回现。
- 带内回显 / 时间延迟 / 带外回连。
- 语言堆栈报错指纹。
- **语言变体**：常见服务端语言各试。

## 5. 证据分级 → 判决映射

**证据阶梯：**
- **铁证（Tier-1，单发可定案）**：带 token 的带外回连；唯一 canary 被回显；真实系统文件内容签名匹配；跨工具 canary 读回成功；求值差分结果回现。
- **可证（Tier-2，需差分/重复）**：受控 A/B 稳定且可重复的分化——时序 K 次过阈值；布尔差分一致；接受/拒绝行为分化。
- **弱证（Tier-3，仅旁证）**：错误指纹、部分反射——单独不足以定案。

**五态判决（在现有四态上细化，新增“疑似有”）：**
- **确认有 CONFIRMED**：出现任一 铁证，或 可证 经重复确认。
- **疑似有 SUSPECTED（新增）**：仅有 弱证、无铁证/可证佐证 → 标记待人工复核。把“看起来有信号但不够硬”从“确认”和“无”里分出来，保护确认数的可信度。
- **疑似无 LIKELY_CLEAN**：**确有证据表明载荷已抵达 sink**（对照调用成功、报错属业务逻辑处理而非前置校验拒绝），且全套套件无任何通道命中。
- **未触达 UNREACHED**：无法把载荷送达 sink（全部在参数校验/形状/前置处失败）——这是**我方失败**，不是服务端安全结论，必须与“疑似无”区分，单列并触发重试/换策略。
- **未测成 SKIPPED**：发射台没搭起来 / 连接中断。

**证据聚合**：多通道独立命中→置信叠加；每个 CONFIRMED 附完整证据包（命中通道、载荷、对照、观测到的差异/命中、可复现调用序列）。

## 6. 抗误报 / 抗抖动机制（强制内建）

- token / canary 足够长且随机、全局唯一，杜绝自然出现造成的假阳。
- 差分探针必带良性对照，判决只认“活性 vs 对照”的差异。
- 时序、崩溃需 K 次重复 + 统计阈值（抵消网络抖动）。
- SSRF 强制边界判别（否则本职功能被误报）。
- 弱证单独出现只给“疑似有”，不进“确认”。

## 7. 执行策略（覆盖优先）

- **默认全量发射**：每个参数跑完其漏洞类的整套套件（技术 × 语境 × 目标变体），**不因“未命中”提前停**。
- **仅 CONFIRMED 后对该参数早停**以省时间；但在研究模式下可配置“继续收齐所有通道证据”。
- **预算基调**：每参数给更长时间 / 更多请求，而非更少。可配 `max_payloads` 放大、`delay`、时序重复次数 `K`、poll 轮次等。
- **通道编排**：带内回显 + 错误指纹为被动顺带观测；带外统一批量 poll；时序单独度量并重复；跨工具在存在配套读/写工具时自动追加。
- **与发射台解耦**：判定只在“发射台已就绪”的前提下运行；发射台失败归 UNREACHED/SKIPPED，不污染判定结论。

## 8. 对论文的意义

相较现有以“带外回连命中即确认”为主的工作，本方法论的差异化：**全通道并覆盖语境/编码/目标变体 + 差分为骨架 + 证据分级五态 + 带外可选**——更全面（召回）、更稳（不依赖出网、抗抖动）、更可信（差分消除本职功能误报、弱证不冒充确认）。判定原语跨漏洞类复用，新增漏洞类是“填套件”的增量。
